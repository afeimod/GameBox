Libretro port
-------------
The prebuilt libgenesis_plus_gx_libretro_android.so shipped in
app/src/main/jniLibs/<abi>/ was obtained from the official libretro
buildbot (https://buildbot.libretro.com/) and is unmodified.

As required by GPLv2 section 3, the corresponding source code is
publicly available at the GitHub repository linked above. To rebuild
the .so from source:
  1. Clone https://github.com/libretro/Genesis-Plus-GX
  2. Run: make -f Makefile.libretro platform=android-arm64
     (or platform=android-armv7 / platform=android-x86_64)
  3. Copy the resulting libgenesis_plus_gx_libretro_android.so to
     app/src/main/jniLibs/<abi>/

BIOS files
----------
Genesis-Plus-GX requires BIOS files (bios_CD_E.zip, bios_CD_J.zip,
bios_CD_U.zip) only for Mega-CD / SEGA-CD disc games. Cartridge games
(MD / SMS / GG / SG) boot directly without BIOS. The BIOS files contain
copyrighted SEGA firmware code and are NOT bundled with this app. See
assets/genesis/README.txt for details on how to obtain and install them.
