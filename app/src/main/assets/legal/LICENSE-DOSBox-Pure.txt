Libretro port
-------------
The prebuilt libdosbox_pure_libretro_android.so shipped in
app/src/main/jniLibs/<abi>/ was obtained from the official libretro
buildbot (https://buildbot.libretro.com/) and is unmodified.

As required by GPLv2 section 3, the corresponding source code is
publicly available at the GitHub repository linked above. To rebuild
the .so from source, follow the build instructions in the DOSBox-Pure
repository's README.

BIOS / ROM files
----------------
DOSBox-Pure does NOT require any BIOS files. DOS games are loaded
directly via their launcher (.bat / .exe / .com / .dosz) and bundled
assets. However, the games themselves are typically copyrighted and
must be obtained legally — see assets/legal/ROM_NOTICE.txt.
