================================================================================
PLATFORM-SPECIFIC ROM SOURCES
================================================================================

NES / FC (FCEUmm core):
  - https://pdroms.de/         (Public-Domain ROMs)
  - https://www.nesdev.org/    (NESdev community homebrew hub)
  - itch.io  (search "NES homebrew")

SNES / SFC (snes9x core):
  - https://pdroms.de/         (Public-Domain ROMs)
  - itch.io  (search "SNES homebrew")

GB / GBC / GBA (mGBA core):
  - https://pdroms.de/         (Public-Domain ROMs)
  - itch.io  (search "GB homebrew" / "GBA homebrew")

DOS (DOSBox-Pure core):
  - https://www.dosgamesarchive.com/
  - https://dosbox.com/  (commercial DOS games must be purchased)

Arcade / FBNeo:
  - https://pdroms.de/   (homebrew arcade ROMs)
  - FBNeo "hacks" section in the official FBNeo GitHub repo
  - Most commercial arcade ROMs (KOF, Metal Slug, Street Fighter II)
    are copyrighted and NOT freely distributable

MD / SMS / GG / SG (Genesis-Plus-GX core):
  - https://pdroms.de/
  - itch.io  (search "Mega Drive homebrew" / "Master System homebrew")
  - SEGA officially allows some non-commercial use of certain old ROMs;
    check SEGA's current licensing terms

J2ME / Java ME:
  - itch.io  (search "J2ME")
  - Personal MIDlet files you have developed

================================================================================
BIOS FILES — READ CAREFULLY
================================================================================

Some cores require BIOS files to boot certain games:

  Core              | BIOS file(s) needed             | When required
-------------------|---------------------------------|---------------------------
  FCEUmm (NES)      | disksys.rom                     | FDS games only (.fds)
  FBNeo (Arcade)    | neogeo.zip, pgm.zip, etc.       | NeoGeo / PGM games
                    |                                 | (CPS1/2/3 games don't
                    |                                 |  need BIOS)
  Genesis-Plus-GX   | bios_CD_E/J/U.zip               | Mega-CD / SEGA-CD games
                    |                                 | (MD/SMS/GG/SG carts
                    |                                 |  don't need BIOS)

ALL BIOS files contain copyrighted code (Nintendo, SNK, IGS, Capcom, SEGA).
NesStation does NOT bundle them — you must obtain them yourself for your
own personal use on hardware you own. See:
  - assets/fbneo/README.txt   for FBNeo BIOS requirements
  - assets/genesis/README.txt for Genesis-Plus-GX BIOS requirements
